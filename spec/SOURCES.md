# Specification sources and response model policy

- [`openapi.json`](openapi.json) is WarEra's published OpenAPI document: <https://api2.warera.io/openapi.json>. Its `info.version` identifies the specification version. Refresh it with `make update-specs`.
- Response models in `models_response.go`, `models_additional.go`, and `models_employees.go` are maintained as Go code in this repository. They are informed by observed API behavior, recorded fixtures, and the [WarEraProjects/TRPC response declarations](https://github.com/WarEraProjects/TRPC/blob/e7b7765d2487b43e01d3b13654bedf9ee5edb16f/src/api/Responses.d.ts) as a reference. The declaration file is not vendored or required by this SDK or its generation workflow.

The OpenAPI document is used to generate request and filter models. Recorded fixtures are examples for decoding and tests; they do not generate response model types. Nullable scalars use pointers where distinguishing `null` from a zero value matters. `json.RawMessage` is reserved for response values whose shape is still undocumented or variable. When endpoint responses change, update the relevant Go model and add or update fixture-backed decoding assertions for the fields the SDK relies on.

Some services wrap procedures the API serves but `openapi.json` does not list, such as `employee.*`, `manager.*`, `managerOffer.*`, `alliance.*`, `war.*`, `party.*`, `election.*`, `donation.*`, `gameStat.*`, `muMember.*`, `muLeague.*`, `muSponsorship.*`, `tournament.*`, `stateArmyExpense.*`, `contribution.*`, `rankingSnapshot.*`, `sanction.*`, `map.getMapData`, `upgrade.getMapUpgrades`, `user.getUserSkills`, and `company.getProductionBonus`. Procedures that act on the caller's own account (`getMy*`, eligibility checks) or that API keys may not call are not wrapped. `cmd/record` always sends `{}`, so fixtures for void-input procedures (`gameStat.getPpMoneyValue`, `gameStat.getPpMoneyValueByItem`, `gameStat.getWorldDevelopment`) are written by hand from the response's `result.data`. The `map.getMapData` response is about 2.7 MB, so its fixture keeps every top-level field but only a few geometries. Their request types are written by hand and their fixtures are recorded with `go run ./cmd/record -method <procedure> -input '<json>'`. Record these from public entities that do not belong to the API key's account, because some procedures answer differently for the owner.
